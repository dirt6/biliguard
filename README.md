# 当真好好学习（Android）

一个自己装的 Android App：**学习清单里的 B 站视频随时能看，其他内容只在自由时段放行，其余时间盖一层遮罩。**

系统自带的「健康使用手机」分不清你看的是网课还是鬼畜，这个 App 就是来解决这件事的。

---

## 一、装到手机

APK：`biliguard-0.1.apk`（33 KB）

**方式 A：手机连电脑装（最快）**

1. 手机打开「开发者选项」→ 打开「USB 调试」
2. 数据线连电脑，手机上点「允许调试」
3. 告诉我，我这边直接执行安装

**方式 B：直接传文件**

把 `biliguard-0.1.apk` 发到手机（微信文件传输助手 / QQ / 数据线 / 云盘都行），
在手机上点开 → 允许「安装未知来源应用」→ 安装。

最低要求：Android 8.0（minSdk 26）。

---

## 二、第一次设置（4 步，约 3 分钟）

### 1. 打开无障碍服务（必须，否则遮罩不工作）

打开 App → 点「打开系统无障碍设置」→ 找到 **「当真好好学习 · 学习模式」** → 打开。

不同品牌的位置：

| 品牌 | 路径 |
|---|---|
| 小米 / 红米 | 设置 → 更多设置 → 无障碍 → 已下载的应用 |
| 华为 / 荣耀 | 设置 → 辅助功能 → 无障碍 |
| OPPO / 一加 / 真我 | 设置 → 系统设置 → 无障碍 |
| vivo / iQOO | 设置 → 快捷与辅助 → 无障碍 |
| 三星 | 设置 → 辅助功能 → 已安装的服务 |
| 原生 Android | 设置 → 无障碍 → 已下载的应用 |

> Android 13 以后系统可能提示「此服务可查看屏幕内容」，这是无障碍服务的固有权限，必须允许。

### 1.5 授予两个辅助权限（必须）

App 顶部状态卡里有对应按钮，点进去授予：

- **使用情况访问**：用来判断"现在前台是哪个 App"。Android 在部分机型上不会把窗口切换事件交给无障碍服务，只能靠这个接口。
- **显示在其他应用上层**：Android 14 以后，无障碍覆盖窗口在部分系统（如小米 HyperOS）上会被**静默丢弃** —— 接口返回成功，但窗口根本不显示。改用标准悬浮窗才稳定。

两个都显示「已授予」才算配置完整。

### 2. 选要管控哪些 App

App 里点「选择应用」，默认已经勾了：**B 站、抖音、快手、小红书、小黑盒**。
可以加别的，也可以全取消只留 B 站。

### 3. 加学习视频（这是核心）

在「学习白名单」里粘贴**视频链接**，点「添加到白名单」。

- **B 站**：链接或 BV 号都行，走官方接口拿准确标题
- **抖音 / 小红书 / 快手 / 微博等**：粘贴分享链接，会跟随短链跳转抓网页标题
- 一次可以粘贴多条
- 抓不到标题时会让你手动填

添加成功后，列表里每条都是**可以点的**——B 站用 `bilibili://` 直接进播放页，其它平台正常打开链接。

### 4. 设自由时段

默认：`11:30-13:00;17:30-19:30`（午饭 + 晚饭）。

规则：**只有这些时间段里，娱乐内容才放行**。其他时间，不在白名单里的视频全部被遮罩挡住。

- 多个时段用 `;` 或 `,` 分隔
- 支持跨天：`23:00-01:00`
- 想更宽/更严自己改，改完点「保存时段」

---

## 三、日常怎么用

**看学习视频**：打开「当真好好学习」→ 点白名单里的条目 → 直接进 B 站看。
（进去后无障碍服务读到标题命中白名单，不会被挡。）

**想看别的**：等自由时段；实在急着看，遮罩上有「临时放行 10 分钟」——**每天只有 2 次**。

**被拦住时**：遮罩上会写下一个自由时段是几点、还有多久开始。

**遮罩背景**：在「遮罩背景图」里可以放**多张**图，每次被拦时随机抽一张铺满屏幕。不上传就是纯黑。

**主界面背景**：同一张卡片里可以「设置主界面背景」，选一张图作为 App 自己的背景；界面上的卡片是 80% 不透明，背景图会透出来。

| | 系统健康使用 | 这个 App |

| 区分学习 / 娱乐 | 不能 | 能（按视频） |
| 同一 App 内分别控制 | 不能 | 能 |

| 自由时段自定义 | 弱 | 能，且支持跨天 |
| 遮罩自定义图片 | 不能 | 能 |
| 一键打开学习视频 | 不能 | 能 |

## 五、不生效怎么排查

按顺序检查：

1. **App 顶部是否显示「无障碍服务：已开启 ✓」**
   没开的话，遮罩根本不会出现。

2. **系统里明明开了，App 却显示未开启**
   这是服务进程被系统强制停止后，vivo / 小米 这类系统会把它记成「已崩溃」且不再重新绑定。
   **重启一次手机**，服务就会恢复。

3. **国产 ROM 杀了后台**
   小米/华为/OPPO 会在清理后台、锁屏久了之后杀掉无障碍服务。
   去设置里给「当真好好学习」：允许自启动、允许后台活动、电池优化设为「不限制」、任务列表里锁定它。

4. **在「选择要管控的 App」里找不到某个应用**
   列表是**按拼音排序**的，中文名不会排在字母后面。
   「哔哩哔哩」在 **B** 段（bilibili），「抖音」在 **D** 段。

5. **B 站里娱乐视频没被挡**
   - 先确认当前不在自由时段
   - 确认 B 站 App 在管控列表里（勾选状态）

6. **学习视频也被挡了**（已大幅缓解，但仍可能发生）
   说明没在屏幕文字里匹配到标题。两个办法：
   - 把标题里的稳定关键词（比如「考研数学」「线性代数」）加到「标题关键词」里
   - 或者用「临时放行 10 分钟」
   如果长期不灵，说明你这版 B 站把标题渲染在无障碍读不到的地方，回来告诉我，我改成别的识别方式。

7. **遮罩闪一下又没了 / 先挡后放**
   正常。页面标题要一两秒才渲染，遮罩会在读到标题后自动撤掉。
   从 App 里点开视频有 8 秒宽限期，不会闪。

8. **添加视频时提示「没找到 BV 号」**
   - 支持：完整链接 `https://www.bilibili.com/video/BVxxxxxxxxxx` 或直接输入 BV 号
   - **不支持 `b23.tv` 短链**（那是会跳转的短地址，解析不了），请在 B 站里点「分享 → 复制链接」后取完整链接，或直接用 BV 号

## 六、已知限制（说清楚，不糊弄）

- **只有 Android**。iOS 不允许第三方 App 盖在别的 App 上面，这条路走不通。
- **识别靠读屏幕文字**。B 站大改版可能让匹配失效，需要更新或改用关键词。
- **自由时段内不设上限**。这是设计如此——你说了那是娱乐时间。
- **临时放行是软限制**（每天 2 次），防的是手滑，不是防存心。真要加密码锁可以下个版本做。
- **无障碍权限很高**：它能读到屏幕上的文字。这个 App 没有联网上传代码，唯一的外网请求是添加白名单时去 B 站公开接口读标题。
- **后台被杀就失效**，需要按上面第 5 节做保活。
- **当前是调试版（debuggable）**，方便我远程排障；功能上和正式版没有区别。

## 七、工程与重新构建

```
bili-guard/
├─ AndroidManifest.xml
├─ res/                        图标、主题、无障碍配置
├─ java/com/biliguard/app/
│  ├─ MainActivity.java        设置界面
│  ├─ GuardService.java        无障碍服务：判断前台 App / 时段 / 白名单
│  ├─ Overlay.java             全屏遮罩（无障碍 overlay 窗口）
│  ├─ Model.java               白名单、时段解析
│  ├─ Match.java               标题归一化与匹配
│  ├─ Prefs.java               本地存储
│  └─ BiliApi.java             读 B 站视频标题
└─ build.ps1                   手工构建脚本（aapt2 + javac + d8 + zipalign + apksigner）
```

改完代码后重新构建：

```powershell
powershell -ExecutionPolicy Bypass -File E:\dsh\bili-guard\build.ps1
```

工具链在 `E:\dsh\_android\`（build-tools 36.1 + android-35 platform），不需要 Android Studio / Gradle。

## 九、更新记录

**第 7 版**
- 修复小米 HyperOS / Android 16 上「完全不弹遮罩」。两个独立原因叠加：
  1. 遮罩窗口用 `TYPE_ACCESSIBILITY_OVERLAY`，系统静默丢弃（`addView` 返回成功但不显示）→ 改用 `TYPE_APPLICATION_OVERLAY`，并给服务加上 `isAccessibilityTool` 标记
  2. 前台判断不可靠：小米不把窗口切换事件交给无障碍服务，桌面/系统组件的事件还会不断抢占 → 改为三级判断：窗口层级（最上层可见应用窗口）→ 使用情况统计 → 事件包名
- 新增两个权限引导：使用情况访问、显示在其他应用上层
- 同一份代码同时适配原生 Android 与国产 ROM，不拆版本

**第 6 版**
- 修复「人已经在桌面了还弹遮罩」：不再是等系统事件更新"当前前台是谁"，而是每次判断都直接向窗口管理器查真实的活动窗口（有些系统切回桌面只发内容变化事件，不发窗口切换事件，导致一直以为还在 App 里）
- 白名单支持任意平台链接：抖音 / 小红书等分享链接会跟随短链抓网页标题，抓不到可手动填
- 遮罩按钮文案从「离开 B 站」改成「离开」（现在管的是多个 App）

**第 5 版**
- 换图标（用户提供的图），应用名改为「当真好好学习」
- 修复遮罩一闪一闪：遮罩窗口自己触发的 `WINDOW_STATE_CHANGED` 会被当成"前台变成自己"，于是收起遮罩、再盖上、来回闪；现在忽略自己包名的事件，并加了 1.2 秒防抖
- 修复点「离开 B 站，去干正事」后桌面仍被遮：原来先撤遮罩再跳桌面，中间 B 站 还在前台，判断又会立刻盖上；现在先进入 6 秒抑制期再撤遮罩和跳转，并把"前台不是受管 App 就立刻撤"提到防抖判断之前
- 注意：**覆盖安装不会刷新 vivo 桌面上已有图标的名字**，卸载重装才会显示新名字

**第 4 版**
- 遮罩图支持多张，每次被拦随机显示一张
- 主界面可以换背景图，卡片 80% 不透明
- 修复服务崩溃：遍历无障碍节点时节点失效会抛异常，导致无障碍服务被系统永久停用（表现就是「切到别的视频完全不拦」）
- 首页状态区分「运行中」/「已开启但没在运行」，后者提示重启手机
- 判断改为三层：标题标记 → 屏幕上半部 → 15 分钟记忆，解决滚动、全屏误拦学习视频

**第 3 版**
- 应用列表按拼音排序（之前中文名被排到最后，找不到「哔哩哔哩」）
- 修复防抖导致判断永不执行
- 修复遮罩显示后读到的是遮罩自身、无法自动撤罩

**第 1-2 版**
- 首个可用版本：白名单、自由时段、遮罩、多 App 管控
